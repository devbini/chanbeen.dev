# 사진 주제 분류

태그 원본은 `photo-topics.json`이다. `photos`의 키는 사진의 원본 경로이며 값은 주제 태그 배열이다. 사진 번호가 바뀌어도 원본 경로가 같으면 분류를 유지한다.

```json
"/photos/20250822_127.jpg": ["landscape", "travel"]
```

2026-10-02 기준 공개 사진 목록의 173장을 썸네일로 검토했다. 피사체가 겹치면 여러 태그를 지정하며, 세 주제에 해당하지 않는 사진은 빈 배열로 두고 전체 목록에서만 표시한다.

| 태그 | 화면 이름 | 기준 | 사진 수 |
| --- | --- | --- | ---: |
| `landscape` | 풍경 | 자연, 하늘, 도시, 건축 등 장소와 장면이 중심인 사진 | 140 |
| `flowers` | 꽃 | 꽃이 주요 피사체인 사진. 꽃밭 등 장소도 강조되면 풍경과 중복 | 33 |
| `travel` | 해외여행 | 사용자가 확인한 해외여행 촬영 기간에 해당하는 사진 | 11 |
| 빈 배열 | 전체에서만 표시 | 현재 세 주제에 해당하지 않는 사진 | 11 |

꽃과 풍경의 경계 등 시각적 판단은 이 JSON에서 수정할 수 있다. 화면의 주제 버튼과 연도 선택은 동시에 적용되며, 모든 결과와 상세 탐색은 촬영일 최신순이다.

## 여행 기간

`travelPeriods`에는 사용자가 알려준 일본 여행 기간을 양 끝 날짜를 포함해 저장했다.

- 2025-08-22 ~ 2025-08-25: 현재 목록의 photo-127 ~ photo-137, 총 11장.
- 2026-07-02 ~ 2026-07-05: 현재 목록에 없음. 현재 최신 촬영일은 2026-04-11.

`photo-topics.ts`가 CDN 사진 목록과 로컬 태그를 연결한다. 기존 경로의 저장된 배열을 우선 적용한다. 새 경로의 사진이 여행 기간에 해당하면 `travel`만 적용하며, 다른 피사체는 추가 검토 후 JSON에 지정한다. 페이지를 열 때 이미지 인식으로 자동 분류하거나 원본 파일을 변경하지 않는다.
